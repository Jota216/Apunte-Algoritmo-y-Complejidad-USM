1. Exponenciación Naive (Potencia Iterativa) Clase 03
Qué hace y cuándo se aplica: Calcula la potencia entera ab (para a, b ≥ 0 enteros) mediante multiplicaciones repetidas acumuladas. Se utiliza como caso introductorio para inducción matemática en invariantes de ciclo y para evidenciar el costo lineal en el valor de b pero exponencial en su número de bits.
Invariante de Ciclo: Antes de cada iteración del ciclo while, se cumple la igualdad: res × ab = aorigborig.
• Inicialización: Antes de la primera iteración, res = 1 y b = borig. Entonces res × ab = 1 × aorigborig = aorigborig (verdadero).
• Mantenimiento: Si es verdadero antes de una iteración con b > 0, en el cuerpo se ejecutan res' = res × a y b' = b − 1. Antes de la siguiente iteración: res' × ab' = (res × a) × ab − 1 = res × ab = aorigborig (se preserva).
• Finalización: Termina cuando b = 0. Luego res × a0 = res × 1 = res = aorigborig. El valor final en res es correcto. 
long long naivePower(long long a, long long b) {
    long long res = 1;
    while (b > 0) {
        res *= a;
        b--;
    }
    return res;
}
Tiempo: O(b) iteraciones = O(2k) (exp. en bits k = ⌊log2 b⌋ + 1) Espacio: O(1)
2. Multiplicación Naive por Sumas Sucesivas Clase 03
Qué hace y cuándo se aplica: Calcula el producto a × b mediante acumulación iterativa de sumas. Modelo canónico de cátedra para conteo de operaciones elementales de CPU (5 op. por ciclo: comparación, 2 lecturas/asignaciones, suma y resta).
Invariante de Ciclo: Antes de cada iteración, se cumple: res + a × b = a × borig.
• Inicialización: res = 0, b = borig ⇒ res + a × b = 0 + a × borig = a × borig.
• Mantenimiento: Ejecutando res' = res + a y b' = b − 1: res' + a × b' = (res + a) + a(b − 1) = res + a + ab − a = res + ab = a × borig.
• Finalización: Al alcanzar b = 0: res + a × 0 = res = a × borig. 
long long naiveMultiplication(long long a, long long b) {
    long long res = 0;
    while (b > 0) {
        res += a;
        b--;
    }
    return res;
}
Tiempo: O(b) sumas elementales (5b + c op. de máquina) Espacio: O(1)
3. Multiplicación Rusa (Russian Peasant) Clase 03
Qué hace y cuándo se aplica: Multiplica dos números enteros no negativos a × b en tiempo logarítmico procesando implícitamente los bits de b desde el menos significativo al más significativo. Si el bit actual es 1 (impar), acumula a; luego duplica a (shift izquierdo) y divide b por 2 (shift derecho).
Descomposición Binaria: b = ∑j=0k−1 bj 2j con bj ∈ {0, 1}. Por tanto, a × b = ∑j=0k−1 bj (a × 2j).
Invariante de Ciclo: En cada iteración se mantiene: res + a × b = aorig × borig.
• Si b es par: a' = 2a, b' = b/2 ⇒ res + a'b' = res + (2a)(b/2) = res + ab.
• Si b es impar: res' = res + a, a' = 2a, b' = (b−1)/2 ⇒ res' + a'b' = res + a + 2a(b−1)/2 = res + ab. 
long long russianPeasant(long long a, long long b) {
    long long res = 0;
    while (b > 0) {
        if (b & 1) { // Evalua si el bit menos significativo es 1 (impar)
            res += a;
        }
        a <<= 1;     // Duplica a (a = a * 2 mediante shift izquierdo)
        b >>= 1;     // Divide b en 2 (b = b / 2 mediante shift derecho)
    }
    return res;
}
Tiempo: ≤ 8 log2 b = O(log b) (lineal en cantidad de bits) Espacio: O(1)
4. Selection Sort con Demostración de Invariantes Clases 02, 04
Qué hace y cuándo se aplica: Ordena un arreglo dividiéndolo en un prefijo ordenado y un sufijo sin ordenar. En cada paso localiza el mínimo del sufijo A[i … n−1] y lo intercambia con A[i]. Minimiza el número de escrituras físicas (a lo sumo n − 1 intercambios).
Invariante Ciclo Interno (j): Antes de cada iteración j ∈ {i+1, …, n−1}, m almacena el índice del menor elemento en A[i … j−1].
• Inicialización: j = i+1, m = i. Rango {A[i]}, m es el mínimo trivial.
• Mantenimiento: Si A[j] < A[m], se actualiza m = j; sino, se preserva. En ambos casos m es el índice del mínimo en A[i … j].
• Finalización: Al terminar j = n, m es el mínimo de todo el sufijo A[i … n−1].
Invariante Ciclo Externo (i): Antes de la iteración i, el prefijo A[0 … i−1] contiene los i menores elementos del arreglo original en orden creciente, y todos son ≤ que cualquier elemento de A[i … n−1]. 
#include <vector>
#include <utility>
using namespace std;

void selectionSort(vector<int>& a) {
    int n = a.size();
    for (int i = 0; i < n - 1; ++i) {
        int m = i; // m almacena el indice del minimo de a[i..n-1]
        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[m]) {
                m = j; // Actualiza posicion del minimo observado
            }
        }
        if (m != i) {
            swap(a[i], a[m]); // Ubica el minimo en su posicion definitiva
        }
    }
}
Comparaciones: ∑i=0n−2(n−1−i) = n(n−1)/2 = Θ(n2) Swaps: ≤ n − 1 • Espacio: O(1)
5. MergeSort (Ordenamiento Divide y Conquista) Clase 02
Qué hace y cuándo se aplica: Algoritmo de ordenamiento clásico por división en mitades. Es estable (mantiene el orden relativo original de elementos iguales) y garantiza cota asintótica estricta Θ(n log n) en todos los casos.
Recurrencia y Teorema Maestro: T(n) = 2T(n/2) + O(n). Con a=2, b=2, d=1, se tiene logb a = log2 2 = 1 = d ⇒ T(n) = Θ(n log n). Árbol de recursión de profundidad log2 n, donde cada nivel realiza O(n) comparaciones en la fusión (merge). 
#include <vector>
using namespace std;

void merge(vector<int>& a, int l, int m, int r) {
    int n1 = m - l + 1, n2 = r - m;
    vector<int> L(n1), R(n2);
    for (int i = 0; i < n1; ++i) L[i] = a[l + i];
    for (int j = 0; j < n2; ++j) R[j] = a[m + 1 + j];

    int i = 0, j = 0, k = l;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) { // <= preserva estabilidad
            a[k++] = L[i++];
        } else {
            a[k++] = R[j++];
        }
    }
    while (i < n1) a[k++] = L[i++];
    while (j < n2) a[k++] = R[j++];
}

void mergeSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(a, l, m);
    mergeSort(a, m + 1, r);
    merge(a, l, m, r);
}
Tiempo: Θ(n log n) en mejor, peor y caso promedio Espacio: O(n) auxiliar
6. QuickSort (Ordenamiento por Partición) Clase 02
Qué hace y cuándo se aplica: Divide y conquista particionando el arreglo alrededor de un elemento pivote in-place. Elementos menores o iguales se ubican a la izquierda y mayores a la derecha; luego ordena recursivamente ambas particiones.
Análisis Asintótico según Pivote:
• Mejor / Promedio: Partición balanceada (n/2). Altura del árbol log2 n. Cada nivel suma n comparaciones ⇒ Θ(n log n).
• Peor Caso: Arreglo ya ordenado o invertido con pivote extremo (0 elementos a un lado, n − 1 al otro) ⇒ T(n) = T(n−1) + O(n) = Θ(n2). 
#include <vector>
#include <utility>
using namespace std;

// Esquema de particion de Lomuto:
int partitionLomuto(vector<int>& a, int low, int high) {
    int pivot = a[high]; // Pivote seleccionado al extremo derecho
    int i = low - 1;
    for (int j = low; j < high; ++j) {
        if (a[j] <= pivot) {
            ++i;
            swap(a[i], a[j]);
        }
    }
    swap(a[i + 1], a[high]); // Ubica pivote en su indice definitivo
    return i + 1;
}

void quickSort(vector<int>& a, int low, int high) {
    if (low < high) {
        int pi = partitionLomuto(a, low, high);
        quickSort(a, low, pi - 1);
        quickSort(a, pi + 1, high);
    }
}
Tiempo: Promedio Θ(n log n) • Peor Caso Θ(n2) Espacio: O(log n) pila recursiva
7. HeapSort (Montículo Binario In-Place) Clase 02
Qué hace y cuándo se aplica: Transforma el arreglo en un Max-Heap in-place. Intercambia la raíz (máximo global) con la última posición del rango y restaura la propiedad de montículo mediante hundimiento (heapify). Garantiza tiempo O(n log n) con memoria adicional O(1).
Indexación del Montículo (0-based): Padre en ⌊(i−1)/2⌋; hijo izquierdo en 2i+1; hijo derecho en 2i+2. Construir el heap de abajo hacia arriba toma ∑h=0log n (n/2h+1) O(h) = O(n). Cada una de las n − 1 extracciones requiere O(log n). 
#include <vector>
#include <utility>
using namespace std;

void heapify(vector<int>& a, int n, int i) {
    int largest = i;
    int l = 2 * i + 1;
    int r = 2 * i + 2;

    if (l < n && a[l] > a[largest]) largest = l;
    if (r < n && a[r] > a[largest]) largest = r;

    if (largest != i) {
        swap(a[i], a[largest]);
        heapify(a, n, largest); // Hundimiento recursivo
    }
}

void heapSort(vector<int>& a) {
    int n = a.size();
    // 1. Build Max-Heap en tiempo O(n)
    for (int i = n / 2 - 1; i >= 0; --i) {
        heapify(a, n, i);
    }
    // 2. Extraer maximos sucesivos y ubicarlos al final
    for (int i = n - 1; i > 0; --i) {
        swap(a[0], a[i]); // Mueve el maximo actual a su posicion definitiva
        heapify(a, i, 0); // Restaura heap sobre los i elementos restantes
    }
}
Tiempo: Θ(n log n) garantizado en todo escenario Espacio: O(1) in-place

8. Test de Primalidad O(√x) para Podas Clase 13
Qué hace y cuándo se aplica: Determina de forma exacta si x > 1 es primo inspeccionando divisores hasta ⌊√x⌋. Se aplica en búsquedas exhaustivas y podas de inviabilidad para descartar candidatos sin incurrir en costo lineal O(x).
Demostración de Cota √x: Si x es compuesto, admite factorización x = a × b. Si ambos factores fuesen > √x ⇒ a × b > √x × √x = x (contradicción). Luego al menos un divisor es ≤ √x. Basta verificar hasta √x. 
bool esPrimo(long long x) {
    if (x <= 1) return false;
    if (x <= 3) return true;
    if (x % 2 == 0 || x % 3 == 0) return false;
    // Salto de 6 en 6 (patron 6k +/- 1 para todo primo > 3)
    for (long long i = 5; i * i <= x; i += 6) {
        if (x % i == 0 || x % (i + 2) == 0) return false;
    }
    return true;
}
Tiempo: O(√x) Espacio: O(1)
9. Generación de Subconjuntos de Tamaño k Clase 13
Qué hace y cuándo se aplica: Genera sistemáticamente todas las combinaciones de tamaño exacto k de un conjunto de n elementos. Evita escribir k ciclos for anidados estáticos y utiliza el parámetro inicio para no repetir elementos ni generar permutaciones redundantes (ej. genera {1, 3} pero descarta {3, 1}).
Propiedad Combinatoria: Cantidad de combinaciones: C(n, k) = n! / (k!(n − k)!). Alcanza su valor máximo en k ≈ n/2.
Poda de Suficiencia: Si actual.size() + (cjto.size() - i) < k, la cantidad de elementos disponibles en el sufijo no alcanza para completar el tamaño k. Se poda inmediatamente el ciclo. 
#include <vector>
using namespace std;

void generarSubconjuntosK(const vector<int>& cjto, vector<int>& actual,
                         int inicio, int k) {
    if ((int)actual.size() == k) {
        // Solucion completa alcanzada: procesar/imprimir actual;
        return;
    }
    // Poda: si los elementos restantes no alcanzan para completar k
    if ((int)actual.size() + ((int)cjto.size() - inicio) < k) return;

    for (int i = inicio; i < (int)cjto.size(); ++i) {
        actual.push_back(cjto[i]);                // 1. ELEGIR
        generarSubconjuntosK(cjto, actual, i + 1, k); // 2. EXPLORAR
        actual.pop_back();                         // 3. DESHACER
    }
}
// Llamada inicial: vector<int> act; generarSubconjuntosK(cjto, act, 0, k);
Tiempo: O(k × C(n, k)) Espacio: O(k) auxiliar (pila de profundidad k)
10. Conjunto Potencia con Máscara de Bits (Bitmask) Clase 14
Qué hace y cuándo se aplica: Genera los 2n subconjuntos de un conjunto de forma puramente iterativa sin llamadas recursivas. Mapea la pertenencia de elementos a los n bits de un entero en [0, 2n − 1]. Ideal para n ≤ 25…30 por su máxima velocidad y nula sobrecarga de stack.
Operaciones a Nivel de Bits:
• 1 << n: Desplaza el bit 1 en n posiciones a la izquierda, produciendo 2n.
• mask & (1 << j): Prueba si el j-ésimo bit está encendido. Si es distinto de 0, el elemento en posición j pertenece al subconjunto. 
#include <vector>
#include <iostream>
using namespace std;

void conjuntoPotenciaBitmask(const vector<int>& cjto) {
    int n = cjto.size();
    int total = 1 << n; // 2^n subconjuntos posibles

    for (int mask = 0; mask < total; ++mask) {
        vector<int> subconjunto;
        for (int j = 0; j < n; ++j) {
            if (mask & (1 << j)) { // j-esimo bit encendido
                subconjunto.push_back(cjto[j]);
            }
        }
        // Procesar subconjunto actual
    }
}
Tiempo: O(n × 2n) Espacio: O(1) adicional (O(n) si almacena)

Qué hace y cuándo se aplica: Genera todos los 2n subconjuntos recorriendo el árbol de decisiones mediante DFS. A diferencia de las permutaciones o combinaciones de tamaño fijo, en este problema cada nodo del árbol es una solución válida (incluido el conjunto vacío inicial).

12. Generación de Permutaciones con Arreglo `usados` Clase 14
Qué hace y cuándo se aplica: Genera las n! permutaciones de un arreglo de n elementos distintos. Como el orden importa ({1, 2} ≠ {2, 1}), el ciclo interno comienza siempre en 0 y un vector booleano usados evita colocar elementos ya presentes en el prefijo.
Estructura del Árbol: A diferencia del conjunto potencia, los nodos internos son permutaciones incompletas; únicamente las hojas a profundidad n (actual.size() == n) constituyen soluciones completas. 
#include <vector>
using namespace std;

void generarPermutaciones(const vector<int>& cjto, vector<int>& actual,
                         vector<bool>& usados) {
    if (actual.size() == cjto.size()) {
        // Solucion completa alcanzada en hoja del arbol:
        // procesar(actual);
        return;
    }

    for (int i = 0; i < (int)cjto.size(); ++i) {
        if (usados[i]) continue;   // Elemento ya forma parte del prefijo
        usados[i] = true;          // 1. ELEGIR
        actual.push_back(cjto[i]);
        generarPermutaciones(cjto, actual, usados); // 2. EXPLORAR
        actual.pop_back();         // 3. DESHACER
        usados[i] = false;
    }
}
// Inicializar: vector<bool> usados(n, false); generarPermutaciones(c, act, usados);
Tiempo: O(n × n!) Espacio: O(n) auxiliar (vector usados y profundidad n)
13. Generación de Permutaciones con `std::next_permutation` Clase 15
Qué hace y cuándo se aplica: Reorganiza un rango in-place para transformarlo en la siguiente permutación en orden lexicográfico. Retorna false cuando se alcanza la permutación descendente máxima. Muy conveniente para recorrer permutaciones cuando no hay podas intermedias.
Mecanismo Interno Canónico (3 pasos):
1. Pivote: Desde la derecha, buscar el primer índice i tal que a[i] < a[i+1]. Si no existe, es la última permutación.
2. Sucesor: Desde la derecha, buscar el primer j tal que a[j] > a[i] e intercambiarlos: swap(a[i], a[j]).
3. Inversión: Invertir el sufijo a[i+1 … n−1] para dejarlo en orden ascendente mínimo. 
#include <vector>
#include <algorithm>
using namespace std;

// 1. Recorrido estandar con la STL:
void recorrerPermutaciones(vector<int> a) {
    sort(a.begin(), a.end()); // Indispensable partir ordenado ascendentemente
    do {
        // Procesar permutacion actual 'a'
    } while (next_permutation(a.begin(), a.end()));
}

// 2. Implementacion interna del algoritmo de std::next_permutation:
bool miNextPermutation(vector<int>& a) {
    int n = a.size(), i = n - 2;
    while (i >= 0 && a[i] >= a[i + 1]) --i; // 1. Buscar pivote
    if (i < 0) return false;                 // Fin de las permutaciones
    int j = n - 1;
    while (a[j] <= a[i]) --j;               // 2. Buscar sucesor
    swap(a[i], a[j]);                        // Intercambiar pivote y sucesor
    reverse(a.begin() + i + 1, a.end());    // 3. Invertir sufijo
    return true;
}
Tiempo: O(n) peor caso por paso • O(n × n!) recorrido completo Espacio: O(1) in-place
14. Backtracking con Podas de Inviabilidad (Suma ≤ S) Clases 13, 14
Qué hace y cuándo se aplica: Patrón de poda de inviabilidad. Al construir una solución parcial con números positivos sujeta a una cota de suma ≤ S, si la suma acumulada supera S, se descarta el subárbol de descendientes, pues con elementos positivos la suma solo puede aumentar.
Ciclo de Decisión: Elegir ⇒ Verificar Factibilidad ⇒ Explorar ⇒ Deshacer.
Al podar antes de invocar la recursión (if (suma + cjto[i] > S) continue;), se ahorra la sobrecarga de entrar a la llamada y crear marcos de pila infructuosos. 
#include <vector>
using namespace std;

void backtrackConPodaInviabilidad(const vector<int>& cjto, vector<int>& actual,
                                 int inicio, int k, int suma, int S) {
    if ((int)actual.size() == k) {
        // Subconjunto de tamano k factible (suma <= S) encontrado
        return;
    }

    for (int i = inicio; i < (int)cjto.size(); ++i) {
        // PODA DE INVIABILIDAD: descarta la rama si sobrepasa la cota S
        if (suma + cjto[i] > S) continue;

        actual.push_back(cjto[i]); // ELEGIR
        backtrackConPodaInviabilidad(cjto, actual, i + 1, k, suma + cjto[i], S); // EXPLORAR
        actual.pop_back();          // DESHACER
    }
}
Tiempo: Acotado por O(k × C(n, k)), drásticamente menor con poda Espacio: O(k)

15. TSP con Poda por Mejor Solución Conocida Clase 15
Qué hace y cuándo se aplica: Encuentra el tour cerrado de menor costo que visita todas las n ciudades exactamente una vez y regresa al origen. Aplica poda cuando el costo acumulado de un camino parcial ya es ≥ mejorCosto conocido.
Simetría y Reducción: Fija la ciudad 0 como punto de partida sin pérdida de generalidad, reduciendo el espacio de búsqueda de n! a (n−1)!.
Poda Incumbente: Como las distancias son no negativas, costo ≥ mejor ⇒ ningún descendiente podrá mejorar a mejor ⇒ podar rama. 
#include <vector>
#include <algorithm>
using namespace std;

int tspBacktracking(int pos, int count, int costo, int n,
                    const vector<vector<int>>& dist,
                    vector<bool>& visitado, int& mejor) {
    // PODA: si el camino parcial ya iguala o empeora la mejor cota
    if (costo >= mejor) return mejor;

    if (count == n) {
        // Se visitaron todas las ciudades: sumar retorno al origen (0)
        mejor = min(mejor, costo + dist[pos][0]);
        return mejor;
    }

    for (int i = 0; i < n; ++i) {
        if (!visitado[i]) {
            visitado[i] = true; // ELEGIR
            tspBacktracking(i, count + 1, costo + dist[pos][i], n, dist, visitado, mejor);
            visitado[i] = false; // DESHACER
        }
    }
    return mejor;
}
// Inicializar: visitado[0]=true, count=1, costo=0, mejor=INF;
Tiempo: Peor caso O((n−1)!), con podas explora una fracción ínfima Espacio: O(n) memoria de visita y pila
16. Esquema General de Branch & Bound (Ramificación y Poda) Clase 15
Qué hace y cuándo se aplica: Generaliza el backtracking en optimización calculando en cada nodo una cota optimista (cota inferior en minimización, cota superior en maximización) del subárbol restante. Si la cota no supera a la mejor solución conocida, descarta la rama entera.
Reglas Fundamentales de Poda B&B:
• Minimización: Cota Inferior = costo_actual + estimacion_optimista_resto. Si LB ≥ mejor, PODAR.
• Maximización: Cota Superior = valor_actual + estimacion_optimista_resto. Si UB ≤ mejor, PODAR.
• Es una búsqueda exacta: una cota válida jamás poda la rama que contiene la solución óptima global. 
// Plantilla generica de Branch & Bound en C++
struct Estado {
    int nivel;
    int acumulado;
    // variables especificas del problema
};

void branchAndBound(Estado s, int& mejorSol) {
    if (esSolucionCompleta(s)) {
        mejorSol = mejor(mejorSol, s.acumulado);
        return;
    }
    // Calculo de cota optimista (LB para min, UB para max)
    int cota = s.acumulado + cotaOptimistaRestante(s);
    if (!puedeSuperar(cota, mejorSol)) return; // PODA B&B

    for (auto decision : ramificar(s)) {
        Estado hijo = aplicar(s, decision);
        branchAndBound(hijo, mejorSol);
    }
}
Propiedad: Búsqueda exacta óptima • Cotas ajustadas maximizan poda Espacio: O(profundidad máxima)
17. Mochila 0/1 con Backtracking y Poda Dual Clase 15
Qué hace y cuándo se aplica: Determina qué objetos incluir en una mochila de capacidad máxima W para maximizar el valor total. Combina poda de inviabilidad por peso con poda por cota superior optimista (Branch & Bound).
Poda Dual Implementada:
1. Poda de Capacidad: Si peso + wt[i] > W, la rama de inclusión es infactible y no se explora.
2. Poda por Cota Superior: Si valor + ∑j=in−1 val[j] ≤ mejorValor, incluso si tomáramos todos los objetos restantes no podríamos superar el óptimo conocido; se poda inmediatamente la rama. 
#include <vector>
#include <algorithm>
using namespace std;

void knapsackBT(int i, int peso, int valor, int remVal, int W,
                const vector<int>& wt, const vector<int>& val,
                int& mejorValor) {
    if (peso > W) return; // Inviabilidad
    mejorValor = max(mejorValor, valor);
    if (i == (int)wt.size()) return;

    // PODA B&B: Si aun tomando todo lo que falta no superamos mejorValor
    if (valor + remVal <= mejorValor) return;

    // Rama 1: Incluir objeto i (si no desborda la capacidad)
    if (peso + wt[i] <= W) {
        knapsackBT(i + 1, peso + wt[i], valor + val[i],
                   remVal - val[i], W, wt, val, mejorValor);
    }
    // Rama 2: Excluir objeto i
    knapsackBT(i + 1, peso, valor, remVal - val[i], W, wt, val, mejorValor);
}
Tiempo: Peor caso O(2n), fuertemente podado con cota acumulada Espacio: O(n) pila recursiva

Fundamento MWIS: Falla de Greedy y Divide & Conquista Clase 01
Problema: En un grafo camino G = (V, E) donde solo hay aristas entre vértices consecutivos vi, vi+1, hallar un conjunto independiente S ⊆ V (sin vértices adyacentes) que maximice la suma de pesos ∑v ∈ S wv.
Por qué falla Greedy: Ordenar por peso y tomar vértices de mayor a menor sin conflicto adyacente falla. Contraejemplo de cátedra: camino de pesos [1, 4, 5, 4]. Greedy toma 5, luego no puede tomar 4 ni 4, y toma 1 ⇒ 5 + 1 = 6. La solución óptima es tomar los dos vértices de peso 4 ⇒ 4 + 4 = 8 > 6.
Por qué falla Dividir y Conquistar: Al partir el camino en dos mitades y unirlas, las soluciones óptimas locales pueden seleccionar vértices en la frontera que resulten adyacentes en el grafo original.
Lema de Subestructura Óptima: Sea S un MWIS de Gn. Se cumple exactamente uno de dos casos:
1. vn ∉ S ⇒ S es un MWIS del prefijo Gn−1.
2. vn ∈ S ⇒ S \ {vn} es un MWIS del prefijo Gn−2.
Recurrencia canónica: W0 = 0, W1 = w1, y para i ≥ 2: Wi = max(Wi−1, Wi−2 + wi).
18. MWIS Top-Down con Memoización (Recursión con Caché) Clase 01
Qué hace y cuándo se aplica: Implementación recursiva natural de la recurrencia que consulta una tabla memo antes de calcular. Resuelve cada uno de los n + 1 subproblemas exactamente una vez, reduciendo la complejidad de exponencial O(2n) a lineal O(n).
Manejo de Índices: Si el vector de pesos w tiene n elementos indexados 0 … n−1, el prefijo Gi comprende los primeros i vértices con peso w[i−1]. 
#include <vector>
#include <algorithm>
using namespace std;

int mwisTopDown(int i, const vector<int>& w, vector<int>& memo) {
    if (i == 0) return 0;
    if (i == 1) return w[0];
    if (memo[i] != -1) return memo[i]; // Subproblema ya resuelto en O(1)

    int excluir = mwisTopDown(i - 1, w, memo);          // Caso 1: no usar v_i
    int incluir = mwisTopDown(i - 2, w, memo) + w[i - 1]; // Caso 2: usar v_i
    return memo[i] = max(excluir, incluir);
}
// Inicializar: vector<int> memo(w.size() + 1, -1);
// Llamar: mwisTopDown((int)w.size(), w, memo);
Tiempo: O(n) (n + 1 subproblemas × O(1) transiciones) Espacio: O(n) tabla memo + pila de recursión
19. MWIS Bottom-Up con Tabulación (Tabla Completa) Clase 01
Qué hace y cuándo se aplica: Resuelve MWIS iterativamente de izquierda a derecha llenando una tabla A[0 … n] en orden ascendente desde los casos base. Es el método estándar cuando además del peso óptimo se requiere reconstruir el conjunto S de vértices elegidos.
Semántica de la Tabla: A[i] guarda el peso del MWIS de Gi. A[0] = 0, A[1] = w[0]. Para i ≥ 2, A[i] = max(A[i−1], A[i−2] + w[i−1]). El valor óptimo final es A[n]. 
#include <vector>
#include <algorithm>
using namespace std;

int mwisBottomUp(const vector<int>& w, vector<int>& A) {
    int n = w.size();
    if (n == 0) return 0;
    A.assign(n + 1, 0);
    A[0] = 0;
    A[1] = w[0];

    for (int i = 2; i <= n; ++i) {
        A[i] = max(A[i - 1], A[i - 2] + w[i - 1]);
    }
    return A[n];
}
Tiempo: O(n) (n − 1 iteraciones con trabajo constante O(1)) Espacio: O(n) para el arreglo de estados A
20. MWIS Bottom-Up con Optimización Espacial O(1) Clase 01
Qué hace y cuándo se aplica: Calcula el peso óptimo de MWIS en espacio adicional constante O(1). Como cada estado A[i] depende únicamente de los dos anteriores (A[i−1] y A[i−2]), se reemplaza el vector completo por dos variables escalares en una ventana deslizante.
Cuándo usarlo: Cuando el problema de certamen solicita exclusivamente el valor numérico óptimo y no la reconstrucción de los vértices que componen la solución. 
#include <vector>
#include <algorithm>
using namespace std;

int mwisO1Space(const vector<int>& w) {
    int n = w.size();
    if (n == 0) return 0;
    if (n == 1) return w[0];

    int prev2 = 0;    // Representa A[i-2], inicialmente A[0] = 0
    int prev1 = w[0]; // Representa A[i-1], inicialmente A[1] = w[0]

    for (int i = 2; i <= n; ++i) {
        int curr = max(prev1, prev2 + w[i - 1]);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1; // Contiene el peso optimo de G_n
}
Tiempo: O(n) Espacio: O(1) memoria adicional constante
21. Algoritmo de Reconstrucción del Conjunto Óptimo S en MWIS Clase 01
Qué hace y cuándo se aplica: A partir de la tabla tabulada A[0 … n], reconstruye en tiempo O(n) la lista exacta de vértices que forman el MWIS realizando un recorrido hacia atrás desde i = n hasta 1.
Regla de Decisión Hacia Atrás:
• Si A[i − 1] ≥ A[i − 2] + w[i − 1] ⇒ el vértice vi NO fue incluido en el óptimo; retroceder a i − 1.
• De lo contrario ⇒ vi SÍ fue incluido; agregarlo a S, y retroceder a i − 2 (pues vi−1 queda forzosamente excluido).
• Caso base i = 1: si se llega a i = 1, el vértice v1 se incluye en S.
Ejemplo Cátedra: w = [3, 2, 1, 6, 4, 5] ⇒ A = [0, 3, 3, 4, 9, 9, 14]. Reconstrucción produce S = {v1, v4, v6} con peso 3 + 6 + 5 = 14. 
#include <vector>
#include <algorithm>
using namespace std;

vector<int> reconstruirMWIS(const vector<int>& A, const vector<int>& w) {
    vector<int> S; // Almacenara los indices de los vertices elegidos
    int i = w.size();

    while (i >= 2) {
        if (A[i - 1] >= A[i - 2] + w[i - 1]) {
            // Se excluye v_i
            i = i - 1;
        } else {
            // Se incluye v_i y se salta forzosamente v_{i-1}
            S.push_back(i); // vertice v_i (1-based: 1 .. n)
            i = i - 2;
        }
    }
    if (i == 1) {
        S.push_back(1); // Vertice v_1 incluido
    }
    reverse(S.begin(), S.end()); // Deja vertices en orden ascendente
    return S;
}
Tiempo: O(n) (≤ n iteraciones con paso 1 o 2) Espacio: O(n) vector resultante S
Fundamento Needleman-Wunsch: Alineamiento Global de Secuencias Clase 03 (Roughgarden Cap. 17)
Problema: Dadas dos secuencias X = x1…xm e Y = y1…yn sobre un alfabeto Σ (e.g. bioinformática {A, C, G, T} o cadenas de texto), hallar una alineación columna a columna insertando espacios (gaps '-') que minimice la penalización total bajo costos αx,y (desajuste/mismatch) y αgap (inserción/borrado).
Lema de Subestructura Óptima (Última Columna): En cualquier alineamiento de X e Y, la última columna corresponde forzosamente a uno de tres casos disjuntos:
• Caso 1 (Símbolo-Símbolo): Se alinean xm con yn. Para que el total sea óptimo, los prefijos x1…xm−1 e y1…yn−1 deben alinearse óptimamente. Costo: Pm−1, n−1 + αxm, yn.
• Caso 2 (Símbolo-Gap en Y): xm se enfrenta a '-'. Queda por alinear óptimamente x1…xm−1 con todo Y. Costo: Pm−1, n + αgap.
• Caso 3 (Gap en X-Símbolo): '-' se enfrenta a yn. Queda por alinear óptimamente todo X con y1…yn−1. Costo: Pm, n−1 + αgap.
Recurrencia de Needleman-Wunsch: Para i = 1…m, j = 1…n:
Pi,j = min { Pi−1,j−1 + αxi,yj, Pi−1,j + αgap, Pi,j−1 + αgap }.
Casos base: P0,0 = 0; Pi,0 = i × αgap (alinear prefijo de X de longitud i con cadena vacía); P0,j = j × αgap.
22. Needleman-Wunsch: DP 2D Bottom-Up (Puntaje Mínimo) Clase 03 (Roughgarden Cap. 17)
Qué hace y cuándo se aplica: Llena sistemáticamente una tabla (m+1) × (n+1) para determinar el puntaje de similitud óptimo entre dos secuencias. Se utiliza en bioinformática (alineamiento ADN/proteínas), corrección ortográfica y cálculo de distancia de edición generalizada.
Semántica de Celda: P[i][j] almacena la penalización mínima de alinear el prefijo X[0…i−1] con Y[0…j−1]. Cada celda se calcula en O(1) consultando diagonal superior izquierda, arriba e izquierda. 
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

int needlemanWunschDP(const string& X, const string& Y, int gapCost, int mismatchCost,
                      vector<vector<int>>& P) {
    int m = X.size(), n = Y.size();
    P.assign(m + 1, vector<int>(n + 1, 0));

    // Casos base: alinear prefijo con cadena vacia
    for (int i = 0; i <= m; ++i) P[i][0] = i * gapCost;
    for (int j = 0; j <= n; ++j) P[0][j] = j * gapCost;

    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            int matchCost = (X[i - 1] == Y[j - 1]) ? 0 : mismatchCost;
            int opMatch = P[i - 1][j - 1] + matchCost; // Caso 1: simbolo-simbolo
            int opGapY  = P[i - 1][j] + gapCost;       // Caso 2: gap en Y
            int opGapX  = P[i][j - 1] + gapCost;       // Caso 3: gap en X
            P[i][j] = min({opMatch, opGapY, opGapX});
        }
    }
    return P[m][n]; // Puntaje minimo global de alineacion
}
Tiempo: O(m × n) (cada celda toma O(1)) Espacio: O(m × n) tabla de programación dinámica
23. Needleman-Wunsch: Reconstrucción (Traceback) y Espacio O(min(m, n)) Clase 03 (Roughgarden Cap. 17)
Qué hace y cuándo se aplica: (1) Reconstruye las secuencias alineadas con sus gaps mediante traceback desde P[m][n] hasta P[0][0]. (2) Permite optimizar el cálculo del costo a O(min(m, n)) espacio con 2 filas si solo se requiere el puntaje numérico.
Traceback hacia atrás: En (i, j), evaluar qué caso originó P[i][j]:
• Diagonal si P[i][j] == P[i−1][j−1] + α ⇒ emitir (X[i−1], Y[j−1]), decrementar i, j.
• Arriba si P[i][j] == P[i−1][j] + αgap ⇒ emitir (X[i−1], '-'), decrementar i.
• Izquierda si P[i][j] == P[i−1][j−1] + αgap ⇒ emitir ('-', Y[j−1]), decrementar j.
Al vaciar i > 0 o j > 0, rellenar con gaps e invertir las cadenas resultantes. 
#include <utility>
// 1. Reconstruccion completa del alineamiento optimo (Traceback):
pair<string, string> reconstruirNW(const string& X, const string& Y,
                                   const vector<vector<int>>& P,
                                   int gapCost, int mismatchCost) {
    string ax = "", ay = "";
    int i = X.size(), j = Y.size();
    while (i > 0 || j > 0) {
        int matchCost = (i > 0 && j > 0) ? ((X[i - 1] == Y[j - 1]) ? 0 : mismatchCost) : -1;
        if (i > 0 && j > 0 && P[i][j] == P[i - 1][j - 1] + matchCost) {
            ax += X[i - 1]; ay += Y[j - 1]; --i; --j;
        } else if (i > 0 && P[i][j] == P[i - 1][j] + gapCost) {
            ax += X[i - 1]; ay += '-'; --i;
        } else {
            ax += '-'; ay += Y[j - 1]; --j;
        }
    }
    reverse(ax.begin(), ax.end());
    reverse(ay.begin(), ay.end());
    return {ax, ay};
}

// 2. Optimizacion espacial O(n) solo para puntaje (2 filas):
int needlemanWunschO_N(const string& X, const string& Y, int gapCost, int mismatchCost) {
    int m = X.size(), n = Y.size();
    vector<int> prev(n + 1), curr(n + 1);
    for (int j = 0; j <= n; ++j) prev[j] = j * gapCost;
    for (int i = 1; i <= m; ++i) {
        curr[0] = i * gapCost;
        for (int j = 1; j <= n; ++j) {
            int matchCost = (X[i - 1] == Y[j - 1]) ? 0 : mismatchCost;
            curr[j] = min({prev[j - 1] + matchCost, prev[j] + gapCost, curr[j - 1] + gapCost});
        }
        prev = curr;
    }
    return prev[n];
}
Traceback: O(m + n) tiempo y espacio Versión Espacio Reducido: O(min(m, n)) memoria
Fundamento Bellman-Ford: Presupuesto de Aristas y Ciclos Negativos Clase 24 (Roughgarden Cap. 18)
Problema: Dado un digrafo G = (V, E) con costos reales cu,v (positivos o negativos) y vértice fuente s, hallar las distancias mínimas dist(s, v) para todo v ∈ V, o detectar la presencia de un ciclo de costo negativo alcanzable desde s.
Por qué falla Dijkstra con aristas negativas: Dijkstra fija vorazmente la distancia de un nodo al extraerlo de la cola de prioridad asumiendo que no puede abaratarse. Con aristas negativas, un camino que parecía más largo puede reducir drásticamente su costo total mediante una arista negativa posterior.
Ciclos Negativos y NP-Hardness: Si existen ciclos con suma de aristas < 0 alcanzables, un camino puede ciclar infinitamente disminuyendo su costo hacia −∞. Si se fuerza a buscar caminos simples (sin repetir nodos) con ciclos negativos presentes, el problema se vuelve NP-Hard (reducción desde Camino Hamiltoniano / Longest Simple Path).
Subproblemas con Presupuesto de Aristas (Roughgarden): Con aristas negativas, el prefijo de un camino más corto no necesariamente tiene menor costo, ¡pero siempre contiene estrictamente menos aristas! Definimos Li,v = costo mínimo de un camino s → v usando a lo más i aristas (i ∈ {0, …, n−1}).
Subestructura Óptima: Un camino óptimo de ≤ i aristas o bien usa ≤ i−1 aristas (Li−1,v), o usa exactamente i aristas terminando en (w, v), cuyo prefijo hasta w usa ≤ i−1 aristas (Li−1,w + cw,v):
Li,v = min { Li−1,v, min(w,v)∈E { Li−1,w + cw,v } }.
Casos base: L0,s = 0; L0,v = +∞ (∀ v ≠ s).
Teorema de Detección: En un grafo de n vértices sin ciclos negativos, todo camino simple tiene ≤ n−1 aristas. Por tanto, Ln−1,v = dist(s, v). Si en la iteración i = n existe algún v tal que Ln,v < Ln−1,v, existe un ciclo negativo alcanzable desde s.
24. Bellman-Ford DP: Formulación 2D Formal con Presupuesto Clase 24 (Roughgarden Cap. 18)
Qué hace y cuándo se aplica: Implementación pedagógica formal de la recurrencia DP de Tim Roughgarden con matriz (n+1) × n. Construye de manera desacoplada las distancias exactas permitiendo a lo más i aristas, garantizando aislamiento estricto entre niveles.
Propiedad Clave: A diferencia de las relajaciones in-place que pueden propagar múltiples aristas en una sola iteración, la matriz 2D restringe exactamente la longitud del camino a i aristas en la fila i. 
#include <vector>
#include <algorithm>
using namespace std;

const long long INF_BF = 1e18; // Evita overflow en sumas

struct Arista { int u, v; long long peso; };

// Retorna matriz L de (n+1) x n. Si detecta ciclo negativo retorna vector vacio.
vector<vector<long long>> bellmanFordDP2D(int n, int s, const vector<Arista>& aristas) {
    // L[i][v]: dist minima de s a v usando a lo mas i aristas
    vector<vector<long long>> L(n + 1, vector<long long>(n, INF_BF));
    L[0][s] = 0; // Caso base: 0 aristas solo alcanzan a la fuente s

    for (int i = 1; i <= n; ++i) {
        // Caso 1: conservar la mejor distancia con a lo mas i-1 aristas
        for (int v = 0; v < n; ++v) L[i][v] = L[i - 1][v];

        // Caso 2: examinar todas las aristas que llegan a v
        for (const auto& e : aristas) {
            if (L[i - 1][e.u] != INF_BF) {
                L[i][e.v] = min(L[i][e.v], L[i - 1][e.u] + e.peso);
            }
        }
    }

    // Comprobacion en iteracion n: si algun nodo mejora, existe ciclo negativo
    for (int v = 0; v < n; ++v) {
        if (L[n][v] < L[n - 1][v]) {
            return {}; // Ciclo negativo alcanzable detectado
        }
    }
    return L; // L[n-1] contiene las distancias mas cortas definitivas
}
Tiempo: O(n × m) (|V| presupuestos × |E| aristas) Espacio: O(n2) para la tabla de programación dinámica
25. Bellman-Ford O(|V|) Espacio con Parada Temprana y Ciclos Negativos Clase 24 / Listado 5
Qué hace y cuándo se aplica: Versión competitiva estándar de Bellman-Ford con vector 1D de distancias. Reduce el espacio a O(|V|). Incorpora bandera cambio para detenerse anticipadamente si las distancias convergen en menos de n−1 fases.
Detección de Ciclo Negativo: Si tras n−1 iteraciones completas se puede seguir relajando al menos una arista en la pasada n, existe un ciclo negativo alcanzable. Si se requiere propagar `-∞` a todos los nodos afectados por el ciclo, se corre un BFS/DFS desde los nodos que aún relajan. 
#include <vector>
#include <iostream>
using namespace std;

const long long INF = 1e18;
struct Edge { int u, v; long long w; };

bool bellmanFordOptimizado(int n, int s, const vector<Edge>& edges,
                          vector<long long>& dist, vector<int>& parent) {
    dist.assign(n, INF);
    parent.assign(n, -1);
    dist[s] = 0;

    // Relajacion iterativa: a lo mas n - 1 fases
    for (int iter = 1; iter < n; ++iter) {
        bool cambio = false;
        for (const auto& e : edges) {
            if (dist[e.u] < INF && dist[e.u] + e.w < dist[e.v]) {
                dist[e.v] = dist[e.u] + e.w;
                parent[e.v] = e.u;
                cambio = true;
            }
        }
        if (!cambio) return true; // Criterio de parada temprana: convergio antes
    }

    // Pasada n para detectar presencia de ciclos negativos alcanzables
    for (const auto& e : edges) {
        if (dist[e.u] < INF && dist[e.u] + e.w < dist[e.v]) {
            return false; // Retorna false: EXISTE ciclo negativo alcanzable
        }
    }
    return true; // Retorna true: distancias optimas libres de ciclos negativos
}
Tiempo: O(|V| × |E|) peor caso • O(k × |E|) con parada Espacio: O(|V|) en vectores dist y parent
Fundamento OBST: Tiempo Promedio, Catalan y Subestructura de Intervalos Clase 05 (Roughgarden Cap. 17)
Problema: Dadas n claves ordenadas k1 < k2 < … < kn con frecuencias de búsqueda conocidas y no negativas p1, p2, …, pn, construir un Árbol de Búsqueda Binaria (BST) T que minimice el tiempo de búsqueda promedio ponderado: ∑i=1n pi × (profundidadT(ki) + 1).
Por qué un árbol balanceado no basta: Un AVL/Red-Black minimiza la altura máxima (O(log n)), optimizando el peor caso. Pero si una clave concentra alta frecuencia (ej. p1 = 0.8), colocarla en la raíz arroja costo promedio ≈ 1.2 comparaciones, mientras que un árbol balanceado forzaría 2 o más comparaciones para la clave más consultada.
Exponencialidad de Fuerza Bruta (Números de Catalan): La cantidad de BSTs distintos formados por n claves ordenadas es Cn = (1 / (n+1)) × (2n sobre n) = Θ(4n / n3/2). Para n = 10 hay 16.796 árboles; para n = 20 supera 6.5 × 109.
Lema 17.4 de Subestructura Óptima (Roughgarden): Si T es un BST óptimo para {k1, …, kn} con raíz r ∈ {1, …, n}:
1. Su subárbol izquierdo debe ser un BST óptimo para las claves {k1, …, kr−1}.
2. Su subárbol derecho debe ser un BST óptimo para las claves {kr+1, …, kn}.
Recurrencia de Intervalos: Sea Wi,j el costo óptimo para el intervalo de claves {ki, …, kj}:
Wi,j = ∑k=ij pk + minr=i…j { Wi, r−1 + Wr+1, j }.
Por qué sumar la suma de frecuencias: Al elegir r como raíz, todas las claves del intervalo aumentan su profundidad en 1 respecto de sus subárboles individuales, sumando 1 × pk por cada clave.
Casos base: Wi,i−1 = 0 (subárbol vacío), Wi,i = pi (un solo nodo).
26. Optimal BST (OBST): DP de Intervalos por Diagonales O(n^3) Clase 05 (Roughgarden Cap. 17)
Qué hace y cuándo se aplica: Calcula el costo de búsqueda ponderado mínimo llenando la matriz W por diagonales (longitud de intervalo s = j − i creciente de 0 a n−1). Almacena las raíces óptimas en R[i][j] para posterior reconstrucción del árbol.
Orden Bottom-Up Estricto: Como Wi,j consulta Wi,r−1 y Wr+1,j (subproblemas de tamaño < s+1), es obligatorio iterar primero por tamaño de intervalo s = 0, 1, …, n−1. La suma de frecuencias ∑k=ij pk se obtiene en O(1) con sumas prefijas. 
#include <vector>
#include <algorithm>
using namespace std;

const double INF_OBST = 1e18;

// Retorna W[1][n] con el costo optimo; llena W y matriz de raices R
double optimalBST(const vector<double>& p, vector<vector<double>>& W,
                  vector<vector<int>>& R) {
    int n = p.size(); // p es 0-based: p[0..n-1]
    // Tablas indexadas 1..n+1 para admitir subproblemas vacios W[i][i-1]
    W.assign(n + 2, vector<double>(n + 2, 0.0));
    R.assign(n + 2, vector<int>(n + 2, 0));

    // Sumas prefijas para calcular sum(p[i..j]) en O(1)
    vector<double> pref(n + 1, 0.0);
    for (int k = 1; k <= n; ++k) pref[k] = pref[k - 1] + p[k - 1];

    // Casos base: subproblemas vacios (j = i - 1) valen 0 (ya asignados)
    // Recorrido por diagonales: s = tamano_intervalo - 1
    for (int s = 0; s < n; ++s) {
        for (int i = 1; i <= n - s; ++i) {
            int j = i + s;
            double sumaP = pref[j] - pref[i - 1];
            double mejorCosto = INF_OBST;
            int mejorRaiz = -1;

            // Probar cada clave r en [i, j] como raiz del subarbol
            for (int r = i; r <= j; ++r) {
                double costo = W[i][r - 1] + W[r + 1][j];
                if (costo < mejorCosto) {
                    mejorCosto = costo;
                    mejorRaiz = r;
                }
            }
            W[i][j] = sumaP + mejorCosto;
            R[i][j] = mejorRaiz;
        }
    }
    return W[1][n];
}
Tiempo: O(n3) (n2/2 subproblemas × O(n) raíces × O(1) suma) Espacio: O(n2) para matrices W y R
27. Reconstrucción del Árbol OBST mediante Tabla de Raíces Clase 05 (Roughgarden Cap. 17)
Qué hace y cuándo se aplica: A partir de la matriz de raíces óptimas R[i][j] calculada por el algoritmo DP, reconstruye la topología completa del árbol binario en tiempo lineal O(n) mediante un recorrido recursivo descendente divide y conquista.
Mecanismo Recursivo: r = R[i][j] es la raíz del subárbol para claves i…j. Su hijo izquierdo se obtiene recursivamente de R[i][r−1] y su hijo derecho de R[r+1][j]. Termina cuando i > j (subárbol vacío). 
#include <vector>
#include <iostream>
using namespace std;

struct NodoBST {
    int clave;
    NodoBST* izq;
    NodoBST* der;
    NodoBST(int k) : clave(k), izq(nullptr), der(nullptr) {}
};

// Construye punteros del arbol a partir de la tabla R:
NodoBST* construirArbolOBST(int i, int j, const vector<vector<int>>& R) {
    if (i > j) return nullptr; // Subarbol vacio
    int r = R[i][j];          // Raiz optima del rango [i..j]
    NodoBST* raiz = new NodoBST(r);
    raiz->izq = construirArbolOBST(i, r - 1, R);
    raiz->der = construirArbolOBST(r + 1, j, R);
    return raiz;
}

// Imprime las relaciones padre-hijo del arbol:
void imprimirEstructura(int i, int j, int padre, bool esIzq,
                        const vector<vector<int>>& R) {
    if (i > j) return;
    int r = R[i][j];
    if (padre == 0) {
        cout << "Clave " << r << " es la RAIZ del arbol global\n";
    } else {
        cout << "Clave " << r << " es hijo " << (esIzq ? "IZQ" : "DER")
             << " de Clave " << padre << "\n";
    }
    imprimirEstructura(i, r - 1, r, true, R);
    imprimirEstructura(r + 1, j, r, false, R);
}
// Llamar con: imprimirEstructura(1, n, 0, false, R);
Tiempo: O(n) (visita exactamente los n nodos del árbol) Espacio: O(n) pila recursiva y estructura de nodos

Definiciones Asintóticas Formales Clase 05
Dadas funciones positivas f(n), g(n):
• f(n) ∈ O(g(n)): ∃ c > 0, n0 > 0 t.q. f(n) ≤ c × g(n), ∀ n ≥ n0 (cota superior asintótica).
• f(n) ∈ Ω(g(n)): ∃ c > 0, n0 > 0 t.q. f(n) ≥ c × g(n), ∀ n ≥ n0 (cota inferior asintótica).
• f(n) ∈ Θ(g(n)): f(n) ∈ O(g(n)) y f(n) ∈ Ω(g(n)) (cota asintótica ajustada).
• f(n) ∈ o(g(n)): limn→∞ (f(n) / g(n)) = 0 • f(n) ∈ ω(g(n)): limn→∞ (f(n) / g(n)) = ∞.
Teorema Maestro (Master Theorem) Clase 05
Para recurrencias de la forma T(n) = a T(n/b) + O(nd) con a ≥ 1, b > 1, d ≥ 0 (donde a: número de subproblemas, b: factor de reducción de tamaño, d: exponente del costo de partición/fusión):
• Caso 1 (d > logb a): El trabajo del nivel raíz domina ⇒ T(n) = Θ(nd).
• Caso 2 (d = logb a): El trabajo está perfectamente balanceado en los logb n niveles ⇒ T(n) = Θ(nd log n).
• Caso 3 (d < logb a): El trabajo en las hojas domina ⇒ T(n) = Θ(nlogb a).
Jerarquía Asintótica de Crecimiento:
1 ≪ log log n ≪ log n ≪ √n ≪ n ≪ n log n ≪ n2 ≪ n3 ≪ 2n ≪ n! ≪ nn.
Propiedades Algebraicas de la Notación Asintótica Apunte Pezoa
Basado en el documento oficial de cátedra (Pezoa - Cormen Cap. 3):
• Transitividad: f ∈ O(g) y g ∈ O(h) ⇒ f ∈ O(h) (análogo para Ω, Θ, o, ω).
• Reflexividad: f ∈ O(f), f ∈ Ω(f), f ∈ Θ(f). (Nota: o y ω NO son reflexivas).
• Simetría: f ∈ Θ(g) ⇔ g ∈ Θ(f).
• Simetría Transpuesta: f ∈ O(g) ⇔ g ∈ Ω(f); f ∈ o(g) ⇔ g ∈ ω(f).
• Suma y Máximo: max{f(n), g(n)} = Θ(f(n) + g(n)).
• Falta de Tricotomía: A diferencia de los reales (<, =, >), dos funciones no siempre son comparables. Contraejemplo de cátedra: f(n) = n y g(n) = n1 + sin n oscilan infinitamente ⇒ f ∉ O(g) y f ∉ Ω(g).
TDAs STL: Complejidades y Costo Amortizado Clase 06
Costo Amortizado de push_back() en std::vector:
Supóngase capacidad inicial 1 que se duplica al llenarse. Para insertar n elementos, cada inserción cuesta 1 (total n), y las copias al redimensionar suman: 1 + 2 + 4 + … + 2k = 2k+1 − 1 < 2n. Costo total de n inserciones < n + 2n = 3n.
Costo amortizado por operación = (Costo total) / n ≤ 3n / n = O(1).
