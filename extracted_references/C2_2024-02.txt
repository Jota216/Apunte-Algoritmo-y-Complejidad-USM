Problema A: El oso negro
Autor: Roberto Asín | Nivel: Intermedio
--------------------------------------------------------------------------------
Contexto:
Un grupo de campistas debe preparar una ofrenda de alimentos para un oso. Se tiene un límite máximo de calorías diarias recomendadas C (1 <= C <= 10000) y n alimentos disponibles (1 <= n <= 1000). Cada alimento i tiene un nombre (string con espacios/letras), un valor calórico VC_i (0 <= VC_i <= 10000) y un índice de sabrosidad para osos ISO_i (0 <= ISO_i <= 10000). Se puede incluir a lo más una unidad de cada alimento.
Problema:
Problema de la Mochila 0/1 (0/1 Knapsack). Maximizar la sabrosidad total (suma de ISO_i) de los alimentos seleccionados sin que la suma de sus calorías (VC_i) exceda C.
Entrada:
- Primera línea: dos enteros n y C (1 <= n <= 1000, 1 <= C <= 10000).
- Siguientes n líneas: nombre_i seguido de VC_i e ISO_i. (nombre compuesto de letras y espacios, los dos últimos tokens de la línea son enteros VC e ISO).
Salida:
- Un número entero correspondiente a la sabrosidad máxima total de la ofrenda.
Ejemplo:
Input:
5 50
brocoli 10 1
hamburguesa vegana 10 3
hamburguesa de carne 25 15
ravioles de acelgas 35 10
marraqueta 10 5
Output:
23

Problema B: Escaleras para salvar el ramo
Autor: Sebastián Torrealba | Nivel: Intermedio
--------------------------------------------------------------------------------
Contexto:
Un estudiante comienza con 1000 puntos y debe subir una escalera de n peldaños numerados 1 a n (1 <= n <= 10^5). Al pisar el peldaño i se le descuenta una penalización p_i (0 <= p_i <= 500). Desde un peldaño se puede avanzar 1, 2 o 3 peldaños a la vez. Se debe comenzar obligatoriamente pisando el peldaño 1 y terminar pisando el peldaño n.
Problema:
Programación Dinámica / Caminos. Encontrar la secuencia de saltos (de tamaño 1, 2 o 3) desde el peldaño 1 hasta el n que minimice la suma de penalizaciones de los peldaños pisados. El puntaje final es 1000 - (penalización mínima acumulada).
Recurrencia: min_cost[i] = p[i] + min({min_cost[i-1], min_cost[i-2], min_cost[i-3]}).
Entrada:
- Primera línea: entero n (1 <= n <= 10^5).
- Segunda línea: n enteros p_1, p_2, ..., p_n (0 <= p_i <= 500).
Salida:
- Un entero indicando el máximo puntaje posible al llegar al último escalón.
Ejemplos:
Input: 1 \n 100 -> Output: 900
Input: 3 \n 0 0 0 -> Output: 1000
Input: 4 \n 5 10 15 20 -> Output: 975 (pisa 1 y 4: 1000 - 5 - 20 = 975)

Problema C: Sebastián Tramposo
Autor: Gabriel Carmona | Nivel: Básico
--------------------------------------------------------------------------------
Contexto:
Duelo de palabras: Carlos tiene la palabra A y Sebastián la palabra B (strings de 1 a 10^5 letras minúsculas). Sebastián puede reordenar las letras de su palabra como desee. Ganará Sebastián si su palabra reordenada es estrictamente menor lexicográficamente que la de Carlos.
Problema:
Greedy / Strings. Para que la palabra de Sebastián sea lo más pequeña posible lexicográficamente, debe ordenarse de forma ascendente (alfabéticamente). Sea B_sorted la palabra de Sebastián ordenada ascendentemente. Sebastián puede ganar si y solo si B_sorted < A lexicográficamente.
Entrada:
- Primera línea: string de Carlos (letras minúsculas, 1 <= len <= 10^5).
- Segunda línea: string de Sebastián (letras minúsculas, 1 <= len <= 10^5).
Salida:
- "Si" si Sebastián puede ganar reordenando sus letras, "No" en caso contrario.
Ejemplos:
Input: numero \n cifra -> Output: Si
Input: abcde \n decab -> Output: No
Input: hola \n hola -> Output: Si (ahlo < hola)

Problema D: Anti-Hacking
Autor: Gabriel Carmona | Nivel: Intermedio
--------------------------------------------------------------------------------
Contexto:
Se tiene un multiconjunto de n letras (1 <= n <= 10). Se quieren generar contraseñas que usen TODOS los n caracteres.
Condiciones de una contraseña fuerte:
1. No debe tener letras repetidas en forma consecutiva (s[i] != s[i+1]).
2. No debe comenzar por el carácter lexicográficamente menor del multiconjunto disponible.
3. Debe usar todos los caracteres del multiconjunto.
Problema:
Backtracking / Permutaciones únicas. Generar o contar todas las permutaciones distintas del multiconjunto que cumplan las restricciones 1 y 2. Dado n <= 10, se puede ordenar el multiconjunto, descartar las ramas donde la primera letra sea la menor, y usar backtracking (o next_permutation saltando duplicados) verificando adyacencias.
Entrada:
- Primera línea: entero n (1 <= n <= 10).
- Segunda línea: n letras del alfabeto inglés separadas por espacio.
Salida:
- Un entero con la cantidad de contraseñas fuertes diferentes.
Ejemplo:
Input: 4 \n b c d b -> Output: 2 (las contraseñas son cbdb y dbcb).

Problema E: Juego del Destino
Autor: Carlos Lagos | Nivel: Intermedio
--------------------------------------------------------------------------------
Contexto:
Grafo conexo no dirigido con n puntos (1 <= n <= 10^5) y m calles (m <= 2*10^5). Cada calle entre a y b tiene f fichas (1 <= f <= 10^9).
Reglas del juego: Robert y Rachele eligen cada uno un punto inicial y visitan todos los puntos.
"No puedes usar una calle que lleva a un punto ya visitado. Te puedes devolver a cualquier punto ya visitado."
Esto implica que el conjunto de calles utilizadas para conectar todos los puntos forma un árbol recubridor (Spanning Tree) de n-1 aristas.
Robert y Rachele buscan maximizar la diferencia entre sus puntajes totales (uno elige el Spanning Tree de peso máximo y el otro el de peso mínimo, recolectando la suma de las fichas de las aristas del árbol).
Problema:
Árbol Recubridor Mínimo y Máximo (Kruskal MST / Maximum Spanning Tree).
La diferencia máxima es: Suma(pesos MaxST) - Suma(pesos MinST).
Entrada:
- Primera línea: n y m.
- Siguientes m líneas: a, b, f (calle entre a y b con f fichas).
Salida:
- Un único entero: la diferencia máxima de fichas.
Ejemplo:
Input:
5 6
1 2 3
2 3 5
2 4 2
3 4 8
5 1 7
5 4 4
Output:
10

Problema F: Viaje Intergaláctico
Autor: Ayleen Irribarra | Nivel: Intermedio
--------------------------------------------------------------------------------
Contexto:
Una nave viaja en línea recta a lo largo de n estaciones (1 <= n <= 10^5) a distancia 1 entre estaciones consecutivas. El estanque tiene capacidad k (1 <= k <= 10^5). El consumo es 1 unidad de combustible por unidad de distancia.
El viaje es de IDA Y VUELTA (de 0 a n y luego de n a 0).
La nave parte con el estanque lleno (k unidades).
Cada estación cobra un precio por unidad de combustible: la primera línea da el precio de la compañía de renta (que cobra por cada unidad faltante al devolver la nave al final en 0), y las siguientes n líneas dan el precio por unidad en cada estación 1 a n (la última línea es la estación n).
Problema:
Greedy / DP de recarga de combustible con capacidad de tanque k.
Entrada:
- Primera línea: n y k.
- Siguiente línea: precio de renta (penalización por unidad vacía al devolver).
- Siguientes n líneas: precio por unidad de combustible en cada estación.
Salida:
- Costo óptimo del viaje.

Problema G: Uno más
Autor: Gabriel Carmona | Nivel: Avanzado
--------------------------------------------------------------------------------
Contexto:
Un profesor tiene n instrucciones binarias de longitud n (1 <= n <= 1000). Falta una instrucción, y se debe generar una nueva cadena binaria de longitud n que sea DIFERENTE a todas las n cadenas dadas.
Problema:
Argumento de la Diagonal de Cantor (Cantor's Diagonalization).
Para construir una cadena binaria ans de largo n que difiera de la i-ésima cadena s_i en la posición i:
ans[i] = (s[i][i] == '0' ? '1' : '0') para todo 0 <= i < n.
Esto garantiza en O(n) tiempo y O(n) espacio que ans difiere de cada s_i en al menos el bit i.
Entrada:
- Primera línea: entero n (1 <= n <= 1000).
- Siguientes n líneas: strings binarios de longitud n.
Salida:
- Un string binario de largo n diferente a todos los entregados.
Ejemplo:
Input:
4
1010
1011
1111
0001
Output:
0101

Problema I: Plagio
Autor: Carlos Lagos | Nivel: Básico
--------------------------------------------------------------------------------
Contexto:
Verificar si el ejercicio de Vicente es una copia del de José.
Transformaciones de Vicente sobre el texto de José:
1. Convierte todo a minúsculas.
2. Reemplaza todas las apariciones de "jose" (incluso como subcadena) por "vicente".
3. Puede cambiar algunas letras a mayúsculas según su criterio.
Problema:
Strings / Normalización. Para verificar:
Pasar ambos strings a minúsculas.
En el texto de José, reemplazar cada "jose" por "vicente".
Comparar si el texto normalizado de José es idéntico al texto normalizado de Vicente.
Si son iguales: "Plagio", si no: "Original".
Entrada:
- Primera línea: texto de José (hasta 10^5 caracteres).
- Segunda línea: texto de Vicente (hasta 10^5 caracteres).
Salida:
- "Plagio" o "Original".

Problema J: Calle Mágica
Autor: Carlos Lagos | Nivel: Avanzado
--------------------------------------------------------------------------------
Contexto:
Calle de n baldosas (1 <= n <= 10^5) con caracteres en minúsculas S[1..n].
Se comienza en baldosa 1 y se debe llegar a la baldosa n.
Movimientos permitidos desde i:
1. Avanzar a i+1 con costo 1.
2. Teletransportarse a j > i de forma gratuita (costo 0) si existe un substring idéntico de largo k >= 1 que comience en i y en j (es decir, si S[i] == S[j], para k=1 ya se cumple!).
Observación crucial del enunciado: "pero solo si existe un substring de longitud k (1 <= k <= n) que comience en la baldosa i y sea idéntico a un substring de longitud k que comience en la baldosa j". Dado que k >= 1, ¡basta con que k=1, lo cual significa S[i] == S[j]! Por tanto, saltar de i a cualquier j con el mismo carácter S[i] == S[j] tiene costo 0.
Problema:
BFS de camino más corto en grafo o DP. Costo 0 para cualquier j con S[j] == S[i], costo 1 para i+1.
Mínimo costo desde 1 a n.
Entrada:
- Una cadena de longitud n (1 <= n <= 10^5).
Salida:
- Entero con el costo mínimo para llegar a n.
